# Front-End

I use this for front-end development work.

## Priorities

- Build clear, maintainable UI.
- Prefer semantic HTML.
- Keep CSS predictable and scoped.
- Protect accessibility, performance, SEO, and user experience.
- Favor existing project patterns over one-off solutions.
- Make implementation choices understandable to a junior developer or future maintainer.

## Review Lens

Check for:

- Semantics
- Keyboard support
- Responsive behavior
- Browser support
- Performance impact
- Visual consistency
- Naming clarity
- Unnecessary complexity
